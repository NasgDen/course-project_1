# Курсовой проект 1

## Описание

Курсовой проект - это консольное приложение написанное на языке программирования Python, в кторорый входит несколько функций для работы с транзакциями.
Приложение для анализа транзакций, которые находятся в Excel-файле. Приложение генерирует JSON-данные для веб-страниц, формирует Excel-отчеты, а также предоставлять другие сервисы.

## Описание функций

1. Модуль utils.py - содержит вспомогательные функции для работы приложения.
* read_xlsx_file - Функция чтение данных из EXCEL файла.
* convert_dataframe_to_list - Функция конвертирует тип DataFrame в Список словарей (list[dict])
* transactions_filter_by_date - Функция приведение дат для фильтрования DataFrame transactions
* get_greeting - Функция возвращает приветствие - «Доброе утро» / «Добрый день» / «Добрый вечер» / «Доброй ночи» в зависимости от текущего времени суток.
* total_sum_cashback_card - Функция принимает DataFrame c транзакциями и выводит по каждой карте: последние 4 цифры карты, общая сумма расходов, кешбэк (1 рубль на каждые 100 рублей).
* top_transactions - Функция принимает DataFrame c транзакциями и дату и возвращает Топ-5 транзакций по сумме платежа.
* get_stock_price - Функция подключается внешнему API - www.alphavantage.co и возвращает стоимость акций из S&P500: "AAPL", "AMZN", "GOOGL", "MSFT","TSLA".
* get_exchange_rate - Функция подключается внешнему API - www.apilayer.com и возвращает курсы валют.
2. Модуль views.py - содержит функцию сбора данных из вспомогательных функций модуля utils.py для страницы 'Главная'
* get_views - Главная функция страницы 'Главная', принимает на вход строку с датой и временем в формате YYYY-MM-DD HH:MM:SS. Возвращающую JSON-ответ.
3. Модуль services.py - содержит различные функции для обработки транзакций.
* get_search - Функция принимает строку для поиска, возвращается JSON-ответ со всеми транзакциями, содержащими запрос в описании или категории.
* investment_bank - Функция принимает список транзакций, порог округления 10, 50 или 100 ₽ и дату. Траты будут округляться, и разница между фактической суммой трат по карте и суммой округления будет попадать на счет «Инвесткопилки».
* get_search_by_tel - Функция возвращает JSON со всеми транзакциями, содержащими в описании мобильные номера.
* get_filter_by_name - Функция возвращает JSON со всеми транзакциями, которые относятся к переводам физлицам. Категория такой транзакции — Переводы, а в описании есть имя и первая буква фамилии с точкой.
4. Модуль reports.py - содержит функции отчетов по транзакциям.
* json_decorator_with_filename - Декоратор с параметром — принимает имя файла в качестве параметра, записывает данные отчета в файл json.
* json_decorator - Декоратор без параметра — записывает данные отчета в файл json с названием по умолчанию (имя файла - название функции).
* spending_by_category - Функция принимает на вход: датафрейм с транзакциями, название категории, опциональную дату. Если дата не передана, то берется текущая дата. Функция возвращает траты по заданной категории за последние три месяца (от переданной даты).
5. Модуль main.py - содержит функцию для запуска проекта.
* main - Главная функция реализующая запуск проекта.

## Установка

1. Клонируйте репозиторий:
```
git clone https://github.com/NasgDen/course-project_1
```
2. В PyCharm установите менеджер проекта poetry.
3. В PyCharm устанавливаем все зависимости проекта из файла pyproject.toml

## Использование:

1. Запустите файл main.py из корневой директории проекта.
2. Введите данные.
3. Просмотрите результат выполнения программы.

## Тестирование модулей

Проводилось тестирование все имеющихся модулей с помощью фрейворка pytest и метрики Code coverage.
Все тесты находятся в папке test.
Результаты покрытия тестов находятся в папку htmlcov.

## Логирование функций

В проекте выполнение всех функции логируются с помощью пакета logging. Log файлы находятся в директории logs. Каждая модуль записывается в свой log файл с именем - 'имя_модуля.log'
